# Pomodoro Timer

A lightweight focus timer plugin for Nidus. Implements the Pomodoro Technique with work sessions, short breaks, and long breaks.

## Features

- 25-minute work sessions
- 5-minute short breaks
- 15-minute long breaks after 4 work sessions
- Audio notification on session completion
- Start, pause, reset, and skip controls

## Usage

1. Select the Pomodoro Timer from the Activity Bar
2. Click **Start** to begin a work session
3. Take a break when the timer completes
4. Click **Skip** to move to the next session early

## Permissions

This plugin requires no special permissions.
